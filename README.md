# Traceable ontology-guided propagation evidence for rumor detection

**Research software and aggregate evidence for an IEEE Transactions on Computational Social Systems manuscript (draft).**

This repository supports the study *Traceable Ontology-Guided Propagation Evidence for Rumor Detection: Rule Verification, Model Sensitivity, and Cross-Domain Stress Tests*. It is designed to **audit reproducibility**, not to claim that hand-designed fuzzy ontology rules reliably improve rumor classification or provide causal/expert-validated explanations.

## Main findings (frozen results)

| Evaluation | Finding | Interpretation |
| --- | --- | --- |
| PHEME v16 leave-one-event-out | Macro-F1 0.71055 (reliability-gated H) vs 0.70902 (raw-evidence C) | Small exploratory difference; not a generalizable gain |
| Twitter15→Twitter16, original trees, full | C 0.7797, D 0.8036 (Δ +0.0239) | Not robust after graph reconstruction |
| Twitter15→Twitter16, strict trees, full | C 0.7892, D 0.7856 (Δ −0.0036) | Original gain changes sign |
| Twitter-COVID19 external (400 events) | Matched threshold: C 0.4744, D 0.4605 Macro-F1, paired Δ CI [−0.0397, +0.0110] | No demonstrated external accuracy benefit |
| Rule execution audit | 216/216 recomputed on source trees, 135 unique source threads | Arithmetic reproduction only |
| Model sensitivity audit | 1,296 rule substitutions, 16 CatBoost models, 2 text preprocessors | Model-score sensitivity, not causal attribution |
| RDF evidence | 60,930 Turtle triples, 216 explanation cases | Structural checks; independent SHACL engine validation remains pending |

**Data access and licensing:** This public-ready directory contains source code and **aggregate/numeric reports**, not raw tweet bodies, source-text snapshots, encoded data-bearing notebooks, or trained text preprocessors. Reconstruct private experimental inputs only from authorized original sources. See `docs/DATA_ETHICS_AND_ACCESS.md` and `docs/REPRODUCTION_GUIDE.md`.

## Repository layout

- `src/pheme/` — latest PHEME v16 components.
- `src/twitter/` — Twitter15/16 frozen pipeline, sensitivity policy audit, and comparative pipeline.
- `src/external/` — Twitter-COVID19 external protocol and archive preflight.
- `src/explanations/` — automatic 216-case audit, provenance/faithfulness code, annotation agreement tools.
- `results/` — selected publication-related **numeric/aggregate** frozen results; these are not regenerated by opening the repository.
- `paper/figures/` — two manuscript figures.
- `notebooks/Verify_Paper_Tables_Offline.ipynb` — checks published numbers without access to tweet data.
- `scripts/` — numeric assertions, checksum checks, and optional SHACL validation.
- `docs/` — per-claim provenance, data permissions and reproduction notes.

## Fast numeric verification

```bash
python scripts/verify_paper_tables.py
python scripts/validate_reproducible_run.py
python scripts/verify_release_sha256.py
```

To validate full RDF after obtaining it from the **separate private archive** and installing optional dependencies:

```bash
python scripts/run_shacl_validation.py --ttl /path/to/all_216_case_provenance.ttl
```

This last command is **not yet an executed result**; record its actual outcome if performed.

## Limitations / scientific integrity

This is a draft research artifact, not final evidence for expert semantic plausibility, OWL-DL entailment, claim truth, or causation. The Twitter15/16 datasets were repeatedly used in development. Twitter-COVID19 is a holdout stress test but uses a *harmonized* feature space without unavailable author identities. The 216 selected cases are not statistically independent (135 unique threads). No raw social-media content is redistributed here. Feature perturbations may produce out-of-manifold combinations.

**Publication status:** manuscript v1 contains red editorial placeholders and is kept out of this public-ready folder until author review. No open-source license is asserted by this package; the authors must choose and add a license intentionally.
